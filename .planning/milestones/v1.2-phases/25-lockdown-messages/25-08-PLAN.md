## Phase Goal

**As a** group owner, **I want** to set what the bot posts in my group when a lockdown starts and when it is lifted, **so that** these messages sound like
my community, while the technical notes, the alerts and every raid-scale path stay exactly as they are and a group that sets nothing sees no change.

<objective>
The closing plan: one end-to-end test that drives the whole phase through the real dispatcher with only Telegram faked (the owner's real presses of the buttons
the bot drew, real typed messages in private, real joins and messages that trip the triggers, real lifts from every door), the phase-wide gates, the one full
run of `fuku/modules` and a final AGENTS.md pass. A production fix is made only when the test finds a defect, in the file it names, and is recorded in the
SUMMARY.

Purpose: the five success criteria, each as an observable behaviour of the running bot.
Output: one test file, AGENTS.md, the phase SUMMARY with EVT-06, EVT-07, EVT-08 and EVT-10 completed.

Test time budget (D-39): about 5 s of the phase's 28 s for `TestLockdownMessagesEndToEnd`; the full package run is made once here and its time recorded.
</objective>
