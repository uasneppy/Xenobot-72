## Phase Goal

As the owner, I can set how my admins' manual punishments behave by default, save short words for common reasons, and give banned people a way to appeal, while a group that sets none of this sees zero change on any command, reply, or punishment.

This plan is the phase's first commit (MSG-11). It freezes every manual command duration-parse refusal, untimed punishment call (no `until_date`), and missing-reason / single-word-reason behavior that Phase 27 will change when configured, before any production file is edited.

<objective>
Record on unchanged commit `b7393953` the characterization goldens of every manual moderation command path Phase 27 touches that `TestLegacyModerationRequests` does not already pin (MSG-11), and commit the golden file alone before any production change.

Purpose: prove byte-identical default behavior for any group that sets no default duration, leaves reason-required off, saves no reason shortcuts, and sets no appeal link.
Output: one new golden test file committed alone.
</objective>
