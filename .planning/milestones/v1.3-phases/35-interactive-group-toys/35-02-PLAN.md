<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted Group Messages → LLM Prompt (`ReferendumUser`, `InspectUser`, `TieBreakerUser`) | Arbitrary member texts, titles, and reply excerpts cross into system/user prompts and could attempt prompt injection. |
| LLM JSON Response → Telegram `SendPoll` / `SetMessageReaction` | Unvalidated model strings could exceed Telegram's 300/100 rune poll bounds, emit duplicate/empty options, or pass non-Telegram lookalike emojis (`😂`, `🐱`, `😹`, `😻`, `😼`). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-35-03 | Tampering / Injection | `ReferendumUser`, `InspectUser`, `TieBreakerUser` (`chatprompt/toys.go`) | medium | mitigate | Sanitize every field via `Clean`, keep static system rules separate, and append explicit untrusted-data framing matching `ReactionUser`. |
| T-35-04 | Tampering / Denial of Service | `ParseReferendumJSON` & `ParseInspectJSON` (`chatprompt/toys.go`) | high | mitigate | Reject trailing tokens after JSON object, enforce Telegram `<= 300` question and `<= 100` option rune limits (`2..5` deduplicated options), strip `U+FE0F`, and intersect reaction emoji strictly with normalized allowed chat palette (failing closed on lookalikes `😂`, `🐱`/`😹`/`😻`/`😼`). |
