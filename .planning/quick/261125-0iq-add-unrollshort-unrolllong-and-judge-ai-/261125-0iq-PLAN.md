| Boundary | Description |
|----------|-------------|
| Telegram member to Redis log | Untrusted member text and names are stored on the bot's own server |
| Redis log to AI provider | A stretch of members' messages leaves the server to Anthropic or Google when a command runs |
| Transcript to prompt | Member-written text is placed inside a model prompt (prompt injection surface) |
| Command sender to /judge | Authority to ask for a scored verdict; anonymous admins have no identity |
| /judge to destinations | The verdict is written to a private chat or a Staff Group chosen by argument or setting |
| Model output to Telegram | AI text is posted in HTML parse mode into a group, a PM or a Staff Group |
