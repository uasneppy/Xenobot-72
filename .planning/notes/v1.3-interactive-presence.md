# v1.3 Interactive Presence — Exploration & Decisions

Goal: Make Xenobot-72 noticeably more interactive and socially aware in groups **without** being annoying, spammy, or out of context.

## Locked-In Product Decisions

1. **Full suite approved** (9 complementary features across 3 phases).
2. **Contextual random AI reactions — media included**: When a photo or sticker wins the sampled roll and the group's provider supports vision (Claude / Gemini), reuse `xenobot/modules/chat_media.go` to send the image/thumbnail. Gracefully fall back to text/caption/sticker-emoji on text-only Featherless models.
3. **Full Telegram emoji palette**: Allow all **73 standard Telegram reaction emojis** (`supportedReactionEmoji` in `xenobot/modules/reactions.go`), including edgy/spicy ones (`🤡`, `💩`, `🤮`, `🖕`, `🤬`) when they genuinely fit Xenobot-72's dry persona — intersected strictly with each group's `ChatFullInfo.AvailableReactions`. Keep `IsBig: false` and default to `NONE` on mundane chatter, unclear sarcasm, moderation drama, or real tragedies/war news.
4. **Permission model**:
   - **AI-backed interactive features** (contextual reactions, ambient room context, `/referendum`, `/inspect`, `✍` PM briefs): **Owner unlocks AI/Conversations per group** (provider + data disclosure notice); once unlocked, **group admins can toggle** individual interactive AI features on/off per chat.
   - **Zero-AI interactive features** (Emoji Consensus, `👎` retraction, smarter static reactions + sticker-emoji triggers, Highlights Archive): **group-admin configurable** independently.
5. **Reaction observation**: Adding `"message_reaction"` to `AllowedUpdates` in `xenobot/config/config.go` is approved as the shared foundation for Emoji Consensus, `👎` retraction, Highlights Archive, and `✍` react-to-brief.

## Suggested 3-Phase Breakdown for Milestone v1.3

### Phase A — Reaction & Social Foundation
- Add `"message_reaction"` to `AllowedUpdates` and wire `handlers.NewReaction`.
- **Contextual Random AI Emoji Reactions**:
  - Strict local gate before any AI call: skip private chats, Staff Groups (`staff.IsStaffGroup`), active lockdowns (`lockdown.GetActive`), bots, anonymous channels, slash commands, and messages already reacted to by static `reactions.go` (mark `ctx.Data` in group `8`).
  - Cross-replica Redis anti-annoyance throttle: message-gap counter (15–30 messages), per-chat cooldown, per-user cooldown, random probability roll, dedicated hourly budget via `chatReserveWith`, frequency presets (`Off / Low / Medium`).
  - Context: last 3–5 same-thread entries from `chat_log.go` when `LogEnabled`, plus free `extraction.ReplyTarget(msg)` / `msg.Quote` even when log is off; photos/stickers via `chat_media.go` on vision-capable providers.
  - Cache per-chat `ChatFullInfo.AvailableReactions` in Redis (15–30 min TTL).
  - Track bot-reacted `(chatID, msgID)` in Redis (24h TTL).
  - Reuse `StopChat` (`chatJobs` + `chatContext`) — zero new shutdown drains.
- **Emoji Consensus (Zero-AI)**: When >= 3 distinct members react to the same message with the same standard emoji, occasionally join in with that exact emoji (behind chat cooldown).
- **`👎` Retraction (Zero-AI)**: When the message author or an admin reacts `👎` to a message Xenobot reacted to, silently clear the bot's reaction (`Reaction: nil`) and extend that user's cooldown.

### Phase B — Community & Zero-AI Polish
- **Smarter Static Reactions** (`xenobot/modules/reactions.go`): Optional word-boundary matching, caption support, trigger chance %, and per-chat/rule cooldowns (plus `ctx.Data` handoff marker for group `13+`).
- **Sticker-Emoji Micro-Triggers (Zero-AI)**: Match Telegram's free `msg.Sticker.Emoji` (e.g., cat stickers `🐱🐈😺😸😹😻😼😽🙀😿😾` → occasional `👀` or `❤` reaction, matching Xenobot-72's canonical cat-collection hobby in `persona.md`).
- **Crowd-Picked Highlights / "Facility Archive" (Zero-AI)**: Aggregate distinct member reactions in Redis (`SADD`/`SREM` with TTL) via `MessageReactionUpdated`; when a message hits the configured threshold, forward/copy it (`ForwardMessage`/`CopyMessage` + `t.me/c/` jump button) into a configured highlights channel or forum topic.

### Phase C — Room-Aware Conversations & Group Toys
- **Ambient Room Context in Conversations**: When `LogEnabled` is on, pass the last 6–10 same-thread entries from `chat_log.go` into `chatBuildRequest` (`xenobot/modules/chat_run.go`) alongside `chatReadHistory`.
- **Frictionless Catch-Up**: Extend `/unrollshort` / `/unrolllong` to support `/unrollshort <N>`, `/unrollshort me` ("since my last message"), `/unrollshort <duration>` (e.g., `2h`), and optional `pm` delivery (reusing `chatJudgeDeliverPrivate`).
- **Silent `✍` React-to-Brief in PM**: Reacting `✍` on a logged message delivers a private `/unrollshort` from that message to the reactor's PM (when `LogEnabled` and the user has started the bot).
- **Vocative Name-Addressing**: Opt-in toggle letting members start a message with `"Xenobot, ..."` / `"Кзенобот, ..."` instead of `@mention` or Reply (safer than an open-mic follow-up timer).
- **Context-Drafted Polls (`/referendum`) + Tie-Breaker**: Read recent thread context (or replied debate) and post one native Telegram poll via `SendPoll`; leverage existing `"poll"` updates (`config.go`) to drop a deadpan 1-line tie-breaker verdict when a bot poll closes in a draw.
- **Playful `/inspect` (or `/rate`)**: Member-accessible sibling to `/judge` — replies to a message/photo/setup/meme with a crisp 2–3 line "Facility Inspection" score and stamps a matching reaction emoji on the target message.

## Verified Codebase Guardrails & Technical Gotchas

- **Thinking-token budget (`MaxTokens`)**: Never set `MaxTokens` to 32–64 for the reaction picker. `gemini-4-hydrogen` cannot turn thinking off (`thinkingLevel: "low"` is the minimum, `xenobot/utils/gemini/client.go:33-35`), and Qwen3 on Featherless spends tokens inside `<think>`. Both return `ErrNoReply` if thinking exhausts `MaxTokens`. Use **`256–512`** and validate in the pre-phase AI spike.
- **Standard reaction emoji validation**: Telegram rejects non-standard emojis (e.g., `🐱`, `🌐`) with `REACTION_INVALID`. Always restrict bot reactions and non-Premium triggers to `supportedReactionEmoji` intersected with `ChatFullInfo.AvailableReactions`.
- **`MessageReactionUpdated` has no message body**: Telegram's Bot API has no `getMessage` method, and `message_reaction_count` fires only for anonymous channel reactions. Group Starboard must aggregate `"message_reaction"` diffs in Redis and use `ForwardMessage`/`CopyMessage`, while `✍` react-to-brief relies on `chat_log.go`.
- **Timestamps in `chat_log.go`**: `chatLogEntry` currently stores `MessageID`, `UserID`, `Name`, `Text`, `Media`, `Thread`, `Edited` — no timestamp field. Add backward-compatible `At int64` (`json:"at,omitempty"`) for time-window catch-up (`/unrollshort 2h`).
- **Settings UI capacity**: Conversations settings page `p` (`xenobot/modules/settings_chat.go`) currently renders 7 rows against an 8-row test cap (`settings_chat_test.go:567`), leaving 1 row for a sub-page link (e.g., `Interactivity →` / `Auto-reactions →`).
- **Explicit safety guards**: Neither `chat_watch.go`, `chat_log.go`, nor `reactions.go` currently checks `staff.IsStaffGroup` or `lockdown.GetActive`. Ambient features must check both explicitly, and silent Telegram `400` failures (deleted message, `REACTION_INVALID`) must never trip provider circuit breakers.
- **Zero shutdown-budget growth**: All new AI work joins `StopChat` (`chatJobs` + `chatContext`), keeping the 70s webhook worst case and `stop_grace_period: 75s` unchanged.
