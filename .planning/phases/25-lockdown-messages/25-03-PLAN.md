## Phase Goal

**As a** group owner, **I want** to set what the bot posts in my group when a lockdown starts and when it is lifted, **so that** these messages sound like
my community, while the technical notes, the alerts and every raid-scale path stay exactly as they are and a group that sets nothing sees no change.

<objective>
Add the Lockdown family with its five events to the Messages page as table rows (D-28), with their strings in all 8 languages; keep 400 units of every
lockdown text for the technical notes through the editor's existing `ReservedText`; draw no private copy row for a lockdown event (D-04); fill the previews
with the trigger samples and the notes; and update the expected shapes of the page's existing tests. The editor definitions still come from the existing
loop over the families, so Set, Remove, the typed-reply door, Silent and the previews work for the new events with no new action code. After this plan the
owner can set the manual start's message on the page and see it at the next `/lockdown` (plan 25-02's site).

Purpose: success criteria 1 to 3's page side; the owner can try the manual start end to end.
Output: the table rows, the sample fields, the strings, the shape edits, the tests and the AGENTS.md lines.

Test time budget (D-39): about 3 s of the phase's 28 s. One environment per dispatcher subtest; language sweeps stay in the existing pure renders of
`settingsMsgScreens`.
</objective>
