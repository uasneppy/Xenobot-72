## Phase Goal

**As a** group owner, **I want** to set what the bot posts in my group when a lockdown starts and when it is lifted, **so that** these messages sound like
my community, while the technical notes, the alerts and every raid-scale path stay exactly as they are and a group that sets nothing sees no change.

<objective>
Extend the Messages page's safety tests to the Lockdown family (forged presses, reads that create nothing, cost, authority, drift, the privacy sweep) and add the
two tests the lockdown sites need: one that no log line carries content, one that no lockdown message names the Staff Group or the log channel. A production
fix is made only when a test finds a defect, in the file it names, and is recorded in the SUMMARY.

Purpose: the page's and the engine's rules hold for the lockdown events (MSG-08, D-31, D-36, D-37) with the light tests the package's time budget allows.
Output: extended safety tests, four new tests and the AGENTS.md lines.

Test time budget (D-39): about 4 s of the phase's 28 s. One environment per test where a dispatcher is needed; the byte and length checks stay in the pure
renders of `settingsMsgScreens` (plan 25-03 already draws the Lockdown family there in 8 languages); the privacy test runs two environments, not a cross product.
</objective>
