## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Settings UI / Repository Callers → `xenobot/db/reactions` → PostgreSQL | Per-rule option values and row IDs cross from admin input into persistent rules and Redis caches. |
| Multi-Replica Cache → Message Watcher (`group 8`) | Cached `reaction_rules:<chat>` entries drive message-path reactions across replicas. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-33-01 | Tampering | `SetReactionOptionsByID` / `reactions` option columns | medium | mitigate | Validate `ValidChancePct` (`1..100`) and `ValidCooldownSecs` (`0..86400`) returning `ErrInvalidOption` before any DB write, enforced in SQL by inline `chk_reactions_chance_pct` and `chk_reactions_cooldown_secs`. |
| T-33-02 | Repudiation / Integrity | `reaction_rules:<chat>` multi-replica cache | medium | mitigate | Register `reaction_rules:` in `skipLocal` (`xenobot/db/cache/local.go`) and drop both `reactions:<chat>` and `reaction_rules:<chat>` on every rule mutation. |
| T-33-03 | Elevation of Privilege | `SetReactionOptionsByID` row ID lookup | high | mitigate | Scope SQL `UPDATE` and read-back strictly with `WHERE id = ? AND chat_id = ?`, returning `(nil, nil)` on cross-chat IDs. |
| T-33-SC | Tampering | Go module dependencies | high | accept | Zero new external Go packages added; uses existing GORM, stdlib, and internal cache packages. |
</threat_model>
