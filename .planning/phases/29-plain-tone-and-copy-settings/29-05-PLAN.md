## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Private callback (`settings\|v1\|a=ck/cy&c=...&t=.../k=...`) → `settings_copy.go` → Redis token + Telegram `getChatMember`/`getChat` + `applyCopySettings` | Untrusted callback data specifies target chat ID or confirm token for cross-group writes. |
| Target-group probe (`ck` with arbitrary negative chat ID `t`) → Telegram API → Callback alert returned to caller | An attacker could probe arbitrary chat IDs to learn whether the bot is in a chat, whether it is a Staff Group, or what its settings access mode is. |
