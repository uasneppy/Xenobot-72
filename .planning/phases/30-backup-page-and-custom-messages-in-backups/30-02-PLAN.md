## Trust Boundaries

|----------|-------------|
| Untrusted backup JSON file (`"messages"` module payload) → `backup.ImportChatDataReport` → `eventmsg.ReplaceAllValidatedTx` → PostgreSQL `chat_event_messages` & `chat_event_message_options` | User-supplied backup JSON could carry malicious button URLs (`javascript:`, `tg://`), oversized texts/captions that break member-requirement or lockdown suffixes, disallowed media types, unknown event keys, or non-object JSON shapes. |
