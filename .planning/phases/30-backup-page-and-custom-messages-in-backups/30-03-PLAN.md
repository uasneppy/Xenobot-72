## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Uploaded `.json` backup document → `downloadAndParseBackupFile` → `settingsBackupPutImportToken` → Redis `fuku:settings:backup:import:<token>` | Parsed backup payload is temporarily stored in Redis between file upload and two-tap Yes confirmation across replicas. |
| Confirm callback (`k=<token>`) → `settingsBackupPeekImportToken` / `settingsBackupConsumeImportToken` / `settingsBackupConsumeResetToken` | Concurrent or replayed Yes presses across replicas could attempt double import or double reset. |

| T-30-06 | Replay / Race Condition | Concurrent or replayed Yes presses on Import or Reset confirm cards across replicas | high | mitigate | 96-bit `crypto/rand` 16-char base64url token stored with `SET NX` and consumed atomically via Lua `GET+DEL` (`settingsCopyConsumeScript`); proven with 8 concurrent goroutines in `import_token_put_peek_consume_and_replay`. |
